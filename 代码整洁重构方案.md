# 代码整洁重构方案

## 重构目标

从代码整洁角度重构前后端代码，提高代码质量、可读性、可维护性和扩展性。

## 代码问题分析

### 前端代码问题

#### 1. API工具类问题
- **语法错误**: `getAuthHeaders()`中的逻辑运算符使用错误
- **类型安全**: 缺少完整的类型定义
- **错误处理**: 错误处理不够详细
- **重复代码**: PageResponse接口在每个Service文件中重复定义

#### 2. Service层问题
- **重复接口**: PageResponse接口在多个文件中重复定义
- **类型不一致**: 返回类型定义不统一
- **魔法数字**: 硬编码的默认值（page: 1, size: 10）
- **错误处理**: 缺少统一的错误处理机制

### 后端代码问题

#### 1. Result类问题
- **方法过多**: 有太多相似的重载方法
- **缺少Builder**: 没有Builder模式支持
- **链式调用**: 不支持链式调用
- **注释冗余**: 注释过于详细，代码本身应该自解释

#### 2. Controller层问题
- **重复代码**: 统计接口的代码逻辑重复
- **硬编码**: 成功消息硬编码在Controller中
- **异常处理**: 异常处理不够统一

#### 2. 重构API工具类
```typescript
// utils/api.ts
const API_CONFIG = {
  DEFAULT_PAGE: 1,
  DEFAULT_SIZE: 10,
  SUCCESS_CODE: '0000'
} as const

export class ApiError extends Error {
  constructor(
    public code: string,
    message: string,
    public details?: unknown
  ) {
    super(message)
    this.name = 'ApiError'
  }
}

export async function processApiResponse<T>(response: Response): Promise<T> {
  if (!response.ok) {
    throw new ApiError(
      response.status.toString(),
      `HTTP error! status: ${response.status}`,
      { status: response.status, statusText: response.statusText }
    )
  }

  const result: ApiResponse<T> = await response.json()

  if (result.code !== API_CONFIG.SUCCESS_CODE) {
    throw new ApiError(result.code, result.msg || 'Backend error')
  }

  return result.data
}

export function getAuthHeaders(): Record<string, string> {
  const token = localStorage.getItem('accessToken')
  return {
    'Content-Type': 'application/json',
    ...(token && { 'Authorization': `Bearer ${token}` })
  }
}

export function buildQueryString(params: Record<string, unknown>): string {
  const searchParams = new URLSearchParams()
  Object.entries(params).forEach(([key, value]) => {
    if (value !== undefined && value !== null && value !== '') {
      searchParams.append(key, String(value))
    }
  })
  return searchParams.toString()
}
```

#### 3. 创建基础Service类
```typescript
// services/baseService.ts
import { getAuthHeaders, processApiResponse } from '@/utils/api'
import type { PageResponse } from '@/types/common'

export abstract class BaseService<T, CreateT = Partial<T>, UpdateT = Partial<T>> {
  protected abstract readonly baseUrl: string

  protected async request<TResponse>(
    url: string,
    options: RequestInit = {}
  ): Promise<TResponse> {
    return processApiResponse<TResponse>(
      await fetch(url, {
        headers: getAuthHeaders(),
        ...options
      })
    )
  }

  async list(params: {
    page?: number
    size?: number
    filters?: Record<string, unknown>
  } = {}): Promise<PageResponse<T>> {
    return this.request<PageResponse<T>>(`${this.baseUrl}/list`, {
      method: 'POST',
      body: JSON.stringify({
        page: params.page ?? 1,
        size: params.size ?? 10,
        filters: params.filters ?? {}
      })
    })
  }

  async getById(id: string | number): Promise<T> {
    return this.request<T>(`${this.baseUrl}/${id}`)
  }

  async create(data: CreateT): Promise<T> {
    return this.request<T>(this.baseUrl, {
      method: 'POST',
      body: JSON.stringify(data)
    })
  }

  async update(id: string | number, data: UpdateT): Promise<T> {
    return this.request<T>(`${this.baseUrl}/${id}`, {
      method: 'PUT',
      body: JSON.stringify(data)
    })
  }

  async remove(id: string | number): Promise<void> {
    return this.request<void>(`${this.baseUrl}/${id}`, {
      method: 'DELETE'
    })
  }
}
```

### 后端重构

#### 1. 重构Result类
```java
// util/Result.java
package com.spec.kit.exam.system.util;

import com.spec.kit.exam.system.enums.ErrorCode;

public final class Result<T> {
    private final T data;
    private final String code;
    private final String msg;

    private Result(T data, String code, String msg) {
        this.data = data;
        this.code = code;
        this.msg = msg;
    }

    public static <T> Result<T> success() {
        return new Result<>(null, "0000", "操作成功");
    }

    public static <T> Result<T> success(T data) {
        return new Result<>(data, "0000", "操作成功");
    }

    public static <T> Result<T> success(T data, String msg) {
        return new Result<>(data, "0000", msg);
    }

    public static <T> Result<T> error(String code, String msg) {
        return new Result<>(null, code, msg);
    }

    public static <T> Result<T> error(ErrorCode errorCode) {
        return new Result<>(null, errorCode.getCode(), errorCode.getMessage());
    }

    public static <T> Result<T> error(ErrorCode errorCode, String customMsg) {
        return new Result<>(null, errorCode.getCode(), customMsg);
    }

    public T getData() {
        return data;
    }

    public String getCode() {
        return code;
    }

    public String getMsg() {
        return msg;
    }

    public boolean isSuccess() {
        return "0000".equals(code);
    }
}
```

package com.spec.kit.exam.system.controller;

import com.spec.kit.exam.system.util.PageRequestDTO;

import java.util.Map;
import java.util.function.Supplier;

public abstract class BaseController<T> {

    protected Map<String, Object> buildStatistics(
        Supplier<Long> totalSupplier,
        Supplier<Long> activeSupplier,
        Supplier<Long> inactiveSupplier
    ) {
        Map<String, Object> statistics = new HashMap<>();
        statistics.put("total", totalSupplier.get());
        statistics.put("active", activeSupplier.get());
        statistics.put("inactive", inactiveSupplier.get());
        return statistics;
    }

    protected Result<Map<String, Object>> successStatistics(Map<String, Object> statistics) {
        return Result.success(statistics, "统计查询成功");
    }
}

3. **代码审查**: 每个阶段完成后进行代码审查
